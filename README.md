# ArtWingman Desktop

Color analysis & paint mixing for painters. This repository only hosts the desktop installers - the app itself is free at **https://artwingman.com** (runs in any browser on Windows, macOS and Linux).

## Download (Windows)

- **Windows x64** (most PCs): [ArtWingman-Setup-x64.exe](https://github.com/manvredo/artwingman-releases/releases/latest/download/ArtWingman-Setup-x64.exe)
- **Windows ARM64** (Snapdragon / Surface Pro X): [ArtWingman-Setup-arm64.exe](https://github.com/manvredo/artwingman-releases/releases/latest/download/ArtWingman-Setup-arm64.exe)

Also available in the [Microsoft Store](https://apps.microsoft.com/detail/9P63N84XHLNP).

**Note:** the installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click **More info -> Run anyway** to install.

macOS / Linux: use the web app at https://artwingman.com/app/
